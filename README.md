# Metodología de desarrollo asistido por IA

Este directorio contiene reglas de trabajo que pueden aplicarse a proyectos distintos de Foraneus: análisis previo, límites de alcance, verificación, documentación, Git y planificación de historias. El contenido fue extraído de la documentación existente en Notion y conserva su intención original.

La organización actual es provisional y está pendiente de revisión humana.
